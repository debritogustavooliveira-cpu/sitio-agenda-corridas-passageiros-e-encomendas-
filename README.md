# 💻 GTEC INFORMÁTICA
### Central de Atendimento e Gestão de Serviços Técnicos

Sistema desenvolvido para gerenciamento de chamados de assistência técnica, acompanhamento de protocolos e controle de atendimentos.

## Funcionalidades

- Abertura de chamados pelos clientes.
- Geração automática de protocolos por ano.
- Consulta de atendimento por protocolo.
- Cadastro de equipamentos.
- Suporte para smartphones, tablets, computadores, roteadores, câmeras IP e outros dispositivos.
- Classificação de prioridade.
- Previsão de atendimento com data e horário.
- Prazo estimado de conclusão.
- Controle de fila de espera.
- Finalização e cancelamento de chamados.
- Histórico de atendimentos.
- Notificações pelo WhatsApp (integração prevista).

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- Supabase (integração prevista)

## Compatibilidade

Sistema desenvolvido para utilização em:
- iPhone
- Android
- Tablets
- Computadores

## Objetivo

Oferecer uma plataforma organizada, prática e profissional para abertura, acompanhamento e gerenciamento de serviços de informática.
